# K-Nearest Neighbors (KNN) classifier to predict Iris flower species from their measurements.
The project loads the Iris dataset, splits it into training and testing sets, trains a KNN model with three neighbors, and 
evaluates its predictions on unseen test data. It also creates visualizations of the training data and test predictions,
highlighting correct and incorrect classifications, and reports the model’s accuracy.

Technologies: Python, scikit-learn, NumPy, Matplotlib

Concepts practiced: Dataset loading, train/test splitting, classification, model prediction, accuracy evaluation, and data visualization.
